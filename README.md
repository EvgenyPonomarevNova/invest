# M1 — investment company website

Multi-page corporate website presenting a Belarus property investment business.

[Open website preview](https://evgenyponomarevnova.github.io/invest/)

## About

A corporate website with separate company, client, partner and contact pages, plus a media-led homepage.

## Status and scope

This is a website frontend, not an investment trading platform or financial analytics engine.

## Run locally

Clone the repository and serve its root with a static HTTP server. For example, with Python installed:

```sh
git clone https://github.com/EvgenyPonomarevNova/invest.git
cd invest
python -m http.server 8080
```

Open [localhost:8080](http://localhost:8080). A static server previews HTML/CSS/JavaScript; it does not execute PHP or connect external form services.
